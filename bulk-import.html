📥 Bulk Import Questions

How to use:
Upload an Excel .xlsx / .xls file or a .csv file. Each row becomes one question.

Two ways to import:
Shift-wise: fill Date and Shift (goes to Subject → Date → Shift folder).
Both: fill Date, Shift and Chapter — the question goes to its shift folder and into chapter mocks.
Chapter-wise: fill Chapter (Date/Shift can be blank) (chapter must already exist). The questions are saved to that Subject → Chapter and also split automatically into mocks of 25 (e.g. 65 questions → Percentage Set 1 = 25, Set 2 = 25, Set 3 = 15) inside Practice Drill → Subject → Chapter.

Required columns:
Subject, Date*, Shift*, Question English, Question Hindi, Option A English, Option A Hindi, Option B English, Option B Hindi, Option C English, Option C Hindi, Option D English, Option D Hindi, Correct

Optional columns: Chapter (required for chapter-wise), Explanation, Bonus, Video Link.

Each row is saved directly to the matching Subject → Date → Shift folder in Date & Shift Question Manager. Subject must already exist. If Chapter is blank, the subject's Shift Import chapter is used (created automatically if needed). Existing questions are not moved or deleted.

Important: Use dates such as 2025-09-17 or 17/09/2025 and shifts 1, 2, 3 or Shift 1, Shift 2, Shift 3. Do not change the question/option column names in the template.
If you pick an exam (e.g. SSC CPO), every question that has a Date + Shift is added to that exam's mock with the same date and shift, in the section of the same subject. Mocks are matched by the date and shift written in the mock title/description (e.g. "15 Nov 2026 – Shift 1").
