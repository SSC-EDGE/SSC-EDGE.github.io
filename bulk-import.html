📥 Bulk Import Questions

How to use:
Upload an Excel .xlsx / .xls file or a .csv file. Each row becomes one question.

Required columns:
Subject, Date, Shift, Question English, Question Hindi, Option A English, Option A Hindi, Option B English, Option B Hindi, Option C English, Option C Hindi, Option D English, Option D Hindi, Correct

Optional columns: Chapter, Explanation, Bonus, Video Link.

Each row is saved directly to the matching Subject → Date → Shift folder in Date & Shift Question Manager. Subject must already exist. If Chapter is blank, the subject's Shift Import chapter is used (created automatically if needed). Existing questions are not moved or deleted.

Important: Use dates such as 2025-09-17 or 17/09/2025 and shifts 1, 2, 3 or Shift 1, Shift 2, Shift 3. Do not change the question/option column names in the template.

🗑 Subject-wise Folder Cleanup

Select a subject, preview its Date/Shift folders, then tick only the folders you want to remove. Unselected folders will remain untouched. Questions themselves are kept in the Question Bank, and questions assigned to mocks/results are not deleted.
Only checked Date/Shift folders will be deleted. You must select them manually after loading the list.
